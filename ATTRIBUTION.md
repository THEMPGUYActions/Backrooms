# Backrooms attribution

The game uses the Backrooms as a source of fictional setting material. The repository does not bundle the Backrooms Wiki's photographs, page artwork, music, or other third-party files. The playable visuals and audio are original procedural work created for this project.

## Backrooms Wiki sources

### Level 0 - "Threshold"

Source:
https://backrooms-wiki.wikidot.com/level-0

The current Level 0 page identifies itself as an adaptation/rewrite credited to DivineAtlas, Robert Goerman and DrAkimoto and also credits the original Backrooms concept on the source page.

Used in this game:
- the Level 0 / Threshold setting
- yellow labyrinthine rooms
- buzzing fluorescent atmosphere
- isolation and disorientation themes
- flickering wall exit concept
- dark sections and floor hazards as game mechanics inspired by the source

### Level 1 - "Habitable Zone"

Source:
https://backrooms-wiki.wikidot.com/level-1

The current page credits Praetor3005 and DivineAtlas and lists earlier origins and rewrites on the source page.

Used in this game:
- the Level 1 / Habitable Zone setting
- corridors, rooms, flickering events and survival-oriented exploration
- green emergency-style exit language
- entity encounters inspired by the page's documented ecosystem

### Level 2 - "Abandoned Utility Halls"

Source:
https://backrooms-wiki.wikidot.com/level-2

The current page credits its current and earlier contributors on the page itself.

Used in this game:
- utility-hall setting
- concrete and industrial styling
- exposed-pipe / machinery atmosphere
- unstable lighting and blackout gameplay
- entity and hazard concepts inspired by the source

## Licensing

The Backrooms Wiki's current licensing guide states that wiki content is generally CC BY-SA 3.0 and gives specific guidance for game developers using wiki material:
https://backrooms-wiki.wikidot.com/licensing-guide

Its image-use guide also says that images need compatible licensing and attribution and excludes unverified copyrighted images and AI-generated images:
https://backrooms-wiki.wikidot.com/image-use-policy

Because this repository contains game adaptations of specific Backrooms Wiki levels/entities, treat the wiki-derived game content as CC BY-SA 3.0 and preserve this attribution when redistributing those derivative portions.

Original project material not derived from the Backrooms Wiki remains subject to the repository's applicable license notices.
