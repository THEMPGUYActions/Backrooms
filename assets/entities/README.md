# Entity model pack

The runtime loads licensed GLB files from this directory when present:

- `smiler.glb` - community model by 🇧🇷 Fog 🇧🇷, CC BY 4.0
  https://sketchfab.com/3d-models/smiler-entity3-backrooms-994d17d347da4806968bb8ed9af5dedd
- `hound.glb` - community model by 🇧🇷 Fog 🇧🇷, CC BY 4.0
  https://sketchfab.com/3d-models/hound-backrooms-b835cbb0440942a0856da6cefd365d38
- `skinstealer.glb` - Speed12 / RocketOfficial, CC BY 4.0
  https://sketchfab.com/3d-models/skin-stealer-the-backrooms-blender-302-c0db7c843ce44bb0a86a0b3a7d7884e1

These are source candidates researched for this project. The binary files are intentionally not ripped from the hosting sites. Add the downloaded source files here only when their download/redistribution terms permit it, and preserve creator attribution.

The game has a procedural fallback so a missing licensed model never breaks the build.
